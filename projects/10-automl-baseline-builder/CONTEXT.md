## Goal

Create a dependency-light AutoML Baseline Builder that demonstrates classic ML baseline automation on a tiny CSV dataset.

## Architecture

- `data/tiny-flowers.csv`: small iris-like classification dataset with numeric features, target label, and deterministic split.
- `src/automl.js`: pure Node.js script for CSV parsing, baseline training, metric calculation, and report generation.
- `reports/`: generated by `npm run eval` with JSON and Markdown outputs.
- `package.json`: local runnable command with no third-party dependencies.

## Decisions Taken

- Used pure JavaScript to avoid package installation cost and keep the project portable.
- Kept the CSV parser minimal because the bundled data has simple comma-separated fields without quoted commas.
- Included majority class and nearest centroid baselines to show both a naive baseline and a simple numeric-feature classifier.
- Ranked recommendations by macro F1 first, then accuracy, because macro F1 better reflects per-class behavior on classification tasks.

## How To Run

```bash
npm install
npm run eval
```
