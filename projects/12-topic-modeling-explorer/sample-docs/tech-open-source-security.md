---
title: Open Source Maintainers Warn About Package Trust
source: 20-newsgroups-like Computing
category: technology
---

Developers in a software forum debated the security of public package registries after several maintainers reported phishing attempts. The discussion focused on signing releases, reviewing build scripts and limiting token permissions. Many contributors argued that open source projects need simpler tools for provenance because small volunteer teams cannot audit every dependency update.
